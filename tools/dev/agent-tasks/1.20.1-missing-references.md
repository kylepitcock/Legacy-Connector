## Known stubs and unsupported parts of the 1.20.1 facades

1.20.1 has no synthesized placeholders yet (an unresolved reference makes the whole mod fail to link; a soft-link mode is being built). The hand-written facades have these known gaps:

- `AttachCapabilitiesEvent`: capability invalidation listeners are not supported (providers live as long as their object).
- `ForgeRegistryWrapper`: registries that are not writable throw `UnsupportedOperationException` on `register`.
- `ITeleporter.getPortalInfo`/`repositionEntity`: vanilla placement is a no-op for the default.
- `RegistryBuilder`/`makeRegistry`: Forge callbacks apply only through `NewRegistryEvent.create`, not `DeferredRegister.makeRegistry`; fields copied by reflection.
- Custom advancement triggers (`DeserializationContext`, `AbstractCriterionTriggerInstance`, `ContextAwarePredicate.ANY`, `SerializationContext`) and `PathPackResources`, recipe serializers (`fromNetwork`/`fromJson`/`toNetwork`) are unbridged (agents are working on them).
- Everything added so far is link-level or server-registration tested only, never played in a client except Terramity.
