# 1.12.2 server-side runtime failures (headless server self test, one mod family at a time)

Method: `run-w12-<name>/mods/1.12.2/` with the family plus its libraries, `./gradlew runServerSubTest -PsubTestDir=run-w12-<name>`, then the
"1.12.2 content registered", "blockstates", "item placement", BLOCK/ITEM/ENTITY SELF TEST lines and the WARN/ERROR classes of the log.
Test artifacts (not defects): `addInformation` on a dedicated server touches client classes (now skipped by the self test); entities the self test
spawns bare (no owner/route/origin) throw in `writeEntityToNBT`/`onUpdate`; "Blocks gone after 60 ticks" lists plants and torches placed without support.
