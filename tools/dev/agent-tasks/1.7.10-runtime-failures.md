## Fixed
- Linker: a call the shim lacks but whose reference arguments are subtypes of a shim method's parameters links to that method (1.5.2 `BlockPistonBase.determineOrientation(..., EntityLiving)` vs 1.7.10 `EntityLivingBase`): Secret Rooms Mod failed with a VerifyError (978da356c, transformer 83).
- `MinecraftServer` shim view is null-safe before the server exists (InventoryPets asked `isDedicatedServer` in preInit); vanilla tile entity ids (`Trap`, `Chest`, `Hopper`...) registered so a mod block hosting a vanilla tile class saves (0a91cd21c).
- `RegistryNamespaced` replacement-by-name table was shared by all registries: HEE's replaced dragon egg block was returned by `Item.itemRegistry.getObject("minecraft:dragon_egg")` (ClassCastException in Thermal Dynamics `ItemCover`); `AllowDespawn` only fires for `EntityLiving` (Erebus cast failure on Betweenlands entities); `Loader.getIndexedModList()` holds entries for the legacy mods present on disk while coremods run (OpenComputers coremod NPE x6); `LivingHurtEvent` re-entrancy follows 1.7.10 hurt resistance (HEE `CurseEvents.onLivingHurt` recursed to a StackOverflow, 598 error blocks) (aee9d1fe7).
- A mod that failed to load no longer receives the server lifecycle events (Morph logged 5 errors).
