# 1.20.1 data census (ATM 9 folder, 555 jars, offline)

How: `python -I tools/compat/data1201.py "<ATM 9 mods>" --json before.json` (what the 1.20.1 data has that 1.21.1 rejects), then
`Data1201Tool <outDir> "<ATM 9 mods>"` (loader `DataConverter1201` over every jar, no game; about 5 min) and the same script over the converted jars.
Files counted once per category. The script knows the format changes listed below only; real parse failures that it cannot see were taken from the
server logs of the `atm9-1201-*` suites (`Parsing error loading recipe`, `Couldn't parse data file`), second table.
