# Survey findings (issue drafts, not filed)

From the first 1.12.2 survey batches (about 75 jars, `tools/survey`), ranked by number of mods affected. Counts grow while the detached run continues; regenerate from `run-survey-main/results/` (raw evidence per jar).

1. **Missing item/block models** (12 of the first ~75 mods; e.g. AE2, AE2WTLib, ArchitectureCraft, BiblioCraft): `ModelBakery` "Unable to load model: 'ns:item/...' referenced from ..." for items whose 1.12 model is a builtin/custom loader or a blockstate-less item. Draft: "1.12.2 items with builtin/custom-loader models have no usable modern item model (missing-texture items)".
2. **Legacy event handlers throwing** (7 mods; AE2WTLib `LibEvents.onItemRegistryReady`, AppleSkin `SyncHandler.onLivingUpdateEvent` on every tick, Arcane World, ArcaneApprentices): "Exception in legacy event handler" in the EventBus bridge. Per-tick ones should be checked for log spam throttling. Draft: "1.12.2 event bridge: handler exceptions (list)".
3. **Entities that render nothing** (7 mods by the pixel heuristic; weak evidence, needs a manual look: Artifacts, Astral Sorcery, Atum, AE2 ...).
4. **Event subscribers that cannot be registered** (4 mods; ArcaneApprentices, Armory Expansion, Block Drops, Construct's Armory): "cannot register the event subscriber ..." (usually an event class the shim lacks).
5. **Load failures for classes the layer should provide** (singles: AppleCore `FoodStats` cannot be cast to `IAppleCoreFoodStats` (ASM-patched vanilla class interfaces are not applied to the shim class); ArchitectureCraft `WrongMethodTypeException` in preInit; Bewitchment `ClassFormatError StackMapTable ... Uninitialized` in `ModRecipes.addOvenRecipes`; BuildCraft Silicon "Scanning facade state"; BuildCraft Transport postInit `Incorrect number of fields`; Chunk Pregenerator / Construct's Armory preInit NPE).
6. **Missing-texture magenta in the block shot** (BuildCraft Transport, Charm).
7. **1.12.2 loot tables that cannot be parsed** ("Attempted to add a duplicate ..."; Ancient Beasts: three tables).
8. **Client crash: CodeChickenLib `WrappedEntityItemRenderer` -> `RenderEntityItem.doRender` -> `drawModern` recursion** (every pack with CCL and a dropped item): StackOverflowError, then `RenderErrors1122` fails to initialise and the client dies in the crash handler. FIXED in this branch (re-entrancy guard in `LegacyEntityRenderer1122.drawModern`).
9. **Mods with the same mod id as a modern perf mod** (1.12.2 Clumps vs Clumps): module resolution error "Modules clumps_legacy and clumps export package com.blamejared.clumps". The survey now leaves the modern jar out; for players this is a pack-level conflict (a legacy jar whose package collides with a NeoForge mod makes the whole game unstartable). Draft: "legacy mod whose Java package equals a NeoForge mod's package aborts module resolution".
10. **Client crash while chunk meshing: `NoClassDefFoundError legacyconnector/v1_12_2/net/minecraftforge/client/MinecraftForgeClient`** seen once with Sodium (Models1122$ModernView.quads). The class exists in source; the run used a main checkout whose build was being recompiled by another agent (stale classes), so treat as environmental unless it reproduces.
11. **Registry entries registered twice** (compactmachines3: Item/SoundEvent "registered twice; keeping the first").
12. **Missing dependencies are not defects of the layer** (about 10 of the first 75 jars fail with NoClassDefFoundError for another mod: libVulpes, InfinityLib, TConstruct, Forestry, JEI, Thaumcraft...). The survey gives them no rating (only "loads" remains) rather than "fails".

## Full survey aggregate (335 1.12.2 jars, 31 1.7.10 jars; counted by mods affected)

The per-mod result files keep only the first 3 log excerpts per namespace (truncated at 250 characters), so counts below are lower bounds. Mods with a log problem: 222 with error lines, 52 with missing texture/model lines, 26 with stack traces.

13. **Coremod plugin class not found** (1.12.2, 14 mods: EnderCore + the 11 EnderIO modules, Mekanism, MDE Core): "Legacy coremod X could not be constructed: ClassNotFoundException" in `CoreModPlugins1122.runAll`, so EnderCore's `EnderCorePlugin.instance()` throws "accessed too early!" (12 mods fail in construction). The translated jar does contain the class (verified for MDE Core with `checkLegacyMod`), so the class lookup through the context class loader at first construct fails at runtime. OPEN: needs a live run (log the loader and the module of the resource URL).
14. **Missing item models** (1.12.2, about 45 mods; ModelBakery "Unable to load model: ns:item/..."): items whose registered model location has no json (custom loaders, baked-model replacements, never registered with ModelLoader). FIXED generically in `Assets1122.itemFallbackModels`: such an item gets a flat model of `textures/items|item/<name>.png` (or its block's model). Remaining: `.tbl` (Mowzie's Mobs Tabula models), `minecraft:block/cube-all` / `cocoa_age*_s` style parents that do not exist in 1.21.1.
15. **Missing dependency mods** (about 20 of the 33 1.12.2 fails: Cyclops Core x3, MCJTY lib x3, Thermal Foundation x3, GottschCore x3, DragonAPI/RotaryCraft x4 in 1.7.10 + 1.12.2, CreativeCore x2, iChunUtil x2, Cucumber x2, ...). Not layer defects.
16. **Constructor-less mod classes** (`NoSuchMethodException <init>()`: Numina, ModularPowersuits, Future MC `PlaySoundAtEntityEvent`): the mod's class has a constructor the shim's/legacy class lacks or private; cases for the shim (PlaySoundAtEntityEvent no-arg constructor).
17. **VerifyError "Bad type on operand stack" / "Bad return type"** in 1.12.2 (ForgeMultipart x3 mods, WR-CBE, Thermal Expansion): a translated class whose operand types do not match the shim. OPEN, needs the verifier output per class (`checkLegacyMod` shows "bytecode verification").
18. **1.7.10 LivingSpawnEvent handlers cast the entity to `EntityLiving`** (Erebus `RandomMobNames`: ClassCastException `EntityBridge$LivingView` cannot be cast to `EntityLiving`): FIXED, vanilla `Mob`s without a dedicated legacy class get a view extending `EntityLiving` (`VanillaMobViews.GenericMobView`).
19. **Per-tick handler exceptions** (1.12.2: AppleSkin `SyncHandler.onLivingUpdateEvent`, Thaumcraft `PlayerEvents.livingTick`, Elenai Dodge 2, LemonLib cooldown, FTB Utilities, Village Names): causes are not in the stored excerpts (stack traces cut); throttling already limits the spam.
20. **Event subscribers that cannot be registered** (15 mods, all but Block Drops/Yabba/Solcarrot are Electroblob's Wizardry add-ons): cause is `NoClassDefFoundError` for another mod (Wizardry, TConstruct, JEI, Forestry) not in the survey set; not layer defects.
21. **1.7.10: two Galacticraft add-ons** (ExtraPlanets, MorePlanet) fail postInit with "Two space station types registered with the same home planet ID: -29". OPEN.
