How it works

Compatibility is determined by running Legacy Connector's translation on the mod jar and validating the result. This runs outside of the game with the checkLegacyMod tool (tools/compat/probe.py); all jars of a run are translated as one mod set, so mods that extend each other link.

Links: every class, method and field the mod uses resolves against the shim, the synthesized legacy API or the libraries. Unresolved: at least one reference cannot be linked and would throw when used. Not applicable: 1.7.10 / 1.12.2 engine patches (performance, bug fixes, ID extenders, mixin loaders) that have nothing to do on 1.21.1.

This only proves a jar translates and links, it does not prove that the mod works in game. Startup problems, bad assumptions about world generation, rendering, or runtime-only failures only show when the game runs, and some unresolved references sit in code paths a mod never reaches. For in-game results see the compatibility list, where player reports and in-game tests outrank this probe.

The jars come from Modrinth's most downloaded Forge mods and are discarded after the run. If a result is wrong, open a compatibility report.
