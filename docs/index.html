How to report a mod

  1. Start the game once with the mod installed; Legacy Connector writes logs/legacyconnector-report.txt.
  2. Press Report a mod (or Report on a mod above). It opens a GitHub issue form with the mod name filled in.
  3. Pick the result, describe what you tried, attach the report file, and submit. The list above updates within a few minutes of your submission.

You need a free GitHub account. Please don't attach mod jars, only logs and screenshots.

Maintainer results come from docs/data/mods.json; community results are generated from issues labelled compatibility.
