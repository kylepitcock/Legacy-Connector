How to report a mod

  1. Start the game once with the mod installed; Legacy Connector writes logs/legacyconnector-report.txt.
  2. Press Report a mod (or Report on a mod above). It opens a GitHub issue form with the mod name filled in.
  3. Pick the result, describe what you tried, attach the report file, and submit. The list above updates within a few minutes of your submission.

You need a free GitHub account. Please don't attach mod jars, only logs and screenshots.

Works = tested in game (by hand, or the in-game test found problems in under 10% of its blocks, items and mobs); Partial = its content loads in game, but some features are broken or not tested yet; Loads = registers at startup without errors, not played yet; Fails = disabled at load; Crashes = takes the game down. Results are per legacy Minecraft version (tab): the same mod can differ on 1.7.10 and 1.12.2. A mod's badge comes from the highest-ranked source: player reports (issues labelled compatibility) outrank maintainer results, which outrank the in-game test (a real modpack session or the self test that places every block, uses every item and spawns every mob), which outranks the automated startup test. The startup test only checks that a mod loads, so any player report replaces it.
