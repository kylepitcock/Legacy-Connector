## Legacy Connector 0.5.1

Bug-fix and compatibility release on top of 0.5.0. Back up worlds before updating; legacy saved data keeps its format.

### Fixed since 0.5.0

**Beta 1.7.3**
- Player momentum survives velocity changes, mounts ignore sneak, mobs hosted from mods walk at the right speed, bone meal works from a stack, Beta dimensions get their biomes, chest-like blocks render and blocks outline with their own selection boxes, container screens opened from ticks get a menu, modifier keys work in screens.

**1.2.5**
- Detected by content wherever the jar sits (`mods/1.4.7/` no longer hides it); 1.2.5 jars are sorted into `mods/1.2.5/`; failures name the jar as Minecraft 1.2.5.
- RedPower (also on 1.4.7, #310 #312): GUIs, multipart blocks picked part by part, tubes, pipes and covers listed in the creative tab, tile entities load.
- Dozens of old API members implemented (rounds 1 and 2).
<!-- lead: add the last merges -->

**1.4.7 to 1.6.4**
- Village buildings of 1.4.7 and 1.5.2 mods are built whole (Forestry apiarist house).
- Thermal Expansion 1.4.7 (#248): machines, energy cells, Tesseract and conduits draw; NEI recipe handlers work through the NEI-to-JEI bridge.
- Forestry and Mystcraft 1.4.7-1.6.4: blocks without an item get one on demand (30 Forestry items were lost), Mystcraft postInit loads.
- Mods that never name a block register it as `block<id>` instead of colliding; tile entities never lose data to a missing id; the 1.2.5 translate table, sound, chat, screen, texture-sheet and cursor APIs are covered.
- Equivalent Exchange 3 and Railcraft 1.6.4 initialise.

**1.7.10**
- Vanilla item base classes get their creative tabs (NTM armor and weapons were missing from Combat, #321); inventory tabs of Galacticraft and Tinkers' Construct work (#318).
- The Legends Mod first-person arm and rendering fixes (#299); Mystcraft chunk handling; faster saves (#306); sounds and GUI events (CustomCursor).
- Vanilla block behaviour mods subclass (torch, slab, ladder, fence gate, wall) and many more old API members.

**1.12.2**
- Twilight Forest hanging entities and generation, Chisel & Bits server crash, Botania/Astral baking crash, Techguns blocks no longer registered twice (#184 container slot listeners, TF2 Stuff Reloaded ammo).
- CodeChickenLib beside the modern one, and a missing required library is reported (#311); item and entity API additions (rails, packets, beacon, tipped arrows).

**Forge 1.20.1**
- Four more rounds of API coverage: Ars Nouveau, Iron's Spells, Cyclops Core, Architectury, Refined Storage, Mekanism, ProjectRed, FTB Chunks, Thermal series and others load or render further.
- Wither Storm and LDLib start-up fixes (#320 #322); Terralith-style 1.20.x data-pack jars are detected and converted; Mixin repair covers handler bodies.

**General**
- A boot crash when another mod (Sinytra Connector) loaded a NeoForge class early is fixed (#311), and the three "mixin not found" errors at every start are gone (#310).
- Legacy ores below y=0 now come from one shifted full-height pass (`deepLayer.mode=shifted`, #82 #295; `split` is the old scheme).
- Libraries that a modern mod nests under `META-INF` no longer clash with the legacy copy (C2ME).
- Tile entities and entities that cannot write their NBT no longer fail chunk saves.

### Known problems
- Thermal Expansion 1.4.7 machines can lose their contents on save.
- 1.20.1: large packs (All the Mods 9) do not stay in a world yet.

Fixes keep arriving in the `nightly` pre-release between stable versions.
